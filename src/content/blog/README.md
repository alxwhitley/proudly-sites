# Blog authoring room

Each article gets one kebab-case folder containing `index.md` and any article-owned images.

Example: `src/content/blog/why-reputation-websites-work/index.md`.

Use the schema in `src/content.config.ts`. Keep unfinished posts marked `draft: true`. Move source notes into the article only after claims and provenance have been checked. Shared brand imagery does not belong here.
